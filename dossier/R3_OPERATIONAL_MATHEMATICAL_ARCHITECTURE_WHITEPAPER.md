## 3.2 Quota Democratization & Capacity-Integrity Scoring Algorithm ($S_{RL}$)

To prevent cartelization, the ODC enforces an automated scoring function. No agency can receive quotas exceeding a hard cap (maximum **2.0% of total corridor volume**).

Demand batches are assigned using the **RL Integrity & Capacity Score ($S_{RL}$)**:

$$S_{RL} = w_1 \cdot C_{valid} + w_2 \cdot Q_{infra} + w_3 \cdot H_{welfare} - w_4 \cdot D_{penalty}$$

Where:
- $C_{valid} \in \{0, 1\}$: Active BMET license validation status (0 = suspended/lapsed, 1 = valid).
- $Q_{infra} \in [0, 1]$: Audited physical and digital infrastructure score (verified counseling desks, biometric enrollment stations, certified trainers).
- $H_{welfare} \in [0, 1]$: Historical worker welfare index (deployment completion rate, zero wage theft complaints, zero contract substitution reports).
- $D_{penalty} \geq 0$: Accumulated penalty points for SLA breaches, sub-agent association, or fee complaints.
- **Weighting Matrix**: $w_1 = 0.40, w_2 = 0.25, w_3 = 0.25, w_4 = 0.50$ (heavily penalized for malpractice).

```python
def calculate_rl_allocation_score(rl_record) -> float:
    """
    Computes RL Integrity & Capacity Score (S_RL) for automated quota distribution.
    Enforces strict zero-tolerance penalty scaling.
    """
    if not rl_record.is_license_active:
        return 0.0
        
    c_valid = 1.0
    q_infra = min(max(rl_record.infra_audit_score / 100.0, 0.0), 1.0)
    h_welfare = min(max(rl_record.welfare_compliance_ratio, 0.0), 1.0)
    d_penalty = float(rl_record.accumulated_penalty_points * 0.10)
    
    score = (0.40 * c_valid) + (0.25 * q_infra) + (0.25 * h_welfare) - (0.50 * d_penalty)
    return max(score, 0.0)
```

## 5.2 Cryptographic Verifiable Random Function (VRF) Allocation Engine

Medical appointments are assigned 24 hours prior to screening using a cryptographically verifiable random distribution algorithm based on **NIST SP 800-90B** entropy:

```
Candidate NID Hash (H_c) ──┐
Current Timestamp (T)   ───┼──> [HMAC-SHA256 / NIST SP 800-90B] ──> Uniform Random Seed (R_i)
Daily Sovereign Seed (S) ──┘                                                    │
                                                                                ▼
District Clinic Capacity Matrix [C_1, C_2, ... C_n] ──────────────> Modulo Index Mapping
                                                                                │
                                                                                ▼
                                                                   Assigned Clinic ID & Token
```

### Mathematical Allocation Formulation:
For candidate $C_i$ with national identity hash $H(NID_i)$ on day $D_j$, the assigned clinic $K_{target}$ within candidate district $Dist_k$ is:

$$R_i = \text{HMAC-SHA256}\left(S_{\text{daily\_seed}}, H(NID_i) \parallel T_{\text{request}} \parallel Nonce\right)$$

$$Index_{clinic} = R_i \pmod{N_{\text{available\_clinics}(Dist_k)}}$$

$$K_{target} = \text{ClinicList}[Index_{clinic}]$$

The daily seed $S_{\text{daily\_seed}}$ is published at 06:00 AM UTC daily, derived from the hash of the latest Bangladesh Bank settlement block, ensuring zero advance predictability and verifiable mathematical fairness.
